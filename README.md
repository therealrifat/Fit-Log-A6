<div align="center">
  <h1>FIT-LOG (Workout Library)</h1>
  <p><strong>FitLog is a modern fitness and workout library tracking web application designed to serve as a dark-themed, no-nonsense gym companion. It allows users to browse a library of exercises, select workouts for their daily routines, track their saved plans, and monitor their progress.</strong></p>
</div>

 **Tech Stack Used**
*  **Next js**
*  **React**
*  **Tailwind-CSS**
*  **JavaScript**
*  **React-Icon**
*  **React-toastify**

------------------------------
 **Project Feature**
*  **[Feature 1 Exercise Library ]:** [Browse 10+ workouts with details like target muscle, duration, calories burned, and required equipment.]
*  **[Feature 2 Client-Side State Management ]:** [Manages dynamic state for adding, removing, and counting items in "My Plan" and "Saved Workouts" in real time.]
*  **[Feature 3 My Plan & Saved ]:** [Easily add exercises to a daily routine or bookmark favorite lifts for quick access.]
*  **[Feature 4 Dynamic Routing ]:** [Uses dynamic pages seamless navigation between workout cards and detail views.]
*  **[Feature 5 Toast Notifications ]:** [Features interactive notification/alert UI feedback to confirm user actions like saving or removing workouts.]
*  **[Feature 6 Dark-Theme UI]:** [A sleek, mobile-friendly dark design built for gym environments and deployed hosted on Netlify.]
